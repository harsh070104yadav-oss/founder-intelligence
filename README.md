# Founder Intelligence

An evolving, continuously updated research and intelligence library covering companies, industries, financials, business models, strategy, technology, distribution, innovation and entrepreneurship.

This repository is designed as a long-term knowledge base for founders seeking deep understanding of how exceptional businesses are built.

---

## Start Here — Single File Reference

**[CUMULATIVE_LEARNINGS.md](CUMULATIVE_LEARNINGS.md)** — the one file that contains all accumulated learnings, patterns, company insights, leadership thinking, distribution lessons, and implications.

Refer to this file only. Everything else in the repository is supporting research that feeds into it.

---

## Supporting Structure

- `daily/` — Consolidated daily founder briefings
- `companies/` — Individual company profiles
- `industries/` — Industry analyses
- `business-models/` — Business model deep dives
- `strategy/` — Strategic topics
- `failures/` — Case studies of failures
- `opportunities/` — Identified opportunities
